# 듣기 정답 자동 추출 (메모)
정답표시 O/X 두 PDF를 같은 쪽끼리 겹쳐 비교해 표시(✓, V)를 찾고, 보기 번호(①~⑤) 위치와 맞춰 정답을 읽습니다.
- 16차 고1: 한 회 5쪽(1+12*(N-1) ~ +4), 17차 중2: 한 회 4쪽(1+16*(N-1) ~ +3, 첫 쪽은 2쪽 펼침)
- 음원: QR 랜딩 페이지(미국식은 왼쪽 QR)의 링크에서 base/prefix를 읽어 data/listening.json 에 기록
- 결과: data/listening.json (books.{id}.keys.{회차} = 20문제 정답, students.{이름} = 책 id)
